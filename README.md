# 💄 GILDED Cosmetics — Salon & Shop Web App

A full-stack salon website built with React TypeScript and Node/Express for a school project.

🔗 **Live Demo:** [gilded-frontend.vercel.app](https://gilded-frontend.vercel.app/home)

---

## ✨ Features

### 🛍️ Shop
- Browse and explore cosmetic products
- Add items to cart
- Choose from **5 delivery options** per item
- Checkout individual items or the entire cart

### 📅 Appointments
- Browse available salon services
- Modify attendees directly from the **service overlay** or the **booking form**
- Booking page includes a live **summary panel** showing:
  - 📆 Date & time
  - 👥 Guest / attendee info
  - 💅 Preferred service

## ▶️ How to Run Locally

### Frontend
```bash
cd front-end
npm install
npm run dev
```

### Backend
```bash
cd backend
npm install
npm run dev
```
